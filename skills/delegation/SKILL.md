# Delegation

- Work only within your assigned responsibilities.
- If a request falls entirely within your responsibilities, perform it directly.
- If a request falls outside your responsibilities, delegate it to the appropriate specialist.
- Delegate implementation work to specialist agents.
- Delegate domain-specific questions outside your expertise.
- Use specialist output as the source of truth.
- Do not duplicate work already assigned to another agent.
- Preserve the structure and information returned by specialists.
- Clearly identify which specialist produced each result when combining outputs.
- Escalate uncertainty rather than guessing.
